# Tarek Buys Houses — 12-State Ambassador Script Library

**Purpose.** All 180+ hook/middle/CTA fragments, rewritten so a Tarek Buys Houses ambassador can deliver them on camera. The voice shifts from Tarek's first-person ("I've helped thousands") to ambassador-on-behalf-of-the-brand ("Tarek and our team have helped thousands"). Same emotional precision, same modular Lego structure, same compliance posture.

**How to use.** Pull the row for the state you're shooting. The blocks are interchangeable — any HOOK + any MIDDLE + any CTA in the same state combines into a working ad. Mix-and-match across short / medium / long durations:
- **Short (15–20s):** Hook + CTA
- **Medium (25–35s):** Hook + Middle + CTA
- **Long (40–60s):** Hook + 2 Middles + CTA

# Voice Tweaks vs. Original (changelog)

The minor adaptations applied across all 60 middles:
- `I've helped thousands` → `Tarek and our team have helped thousands` / `Tarek Buys Houses has helped thousands`
- `I can help` → `we can help` / `Tarek Buys Houses can help`
- `I'll walk you through` → `we'll walk you through`
- `message me` → `message us` (CTAs only when "me" appeared)
- Universal Tarek Buys Houses closer appended optionally at end of long-form spots

Hooks stayed almost entirely intact — they are situation-first, ambassador-agnostic. CTAs flip first-person pronouns to "us / we" only.
