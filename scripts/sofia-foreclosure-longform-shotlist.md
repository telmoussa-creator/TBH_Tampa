## ffmpeg concat (if you download the files locally)

Save the URL list above as `clips.txt`. Then on a Mac with ffmpeg installed:

```bash
# 1. Download all
mkdir -p sofia_longform && cd sofia_longform
xargs -n 1 curl -O < ../clips.txt

# 2. Build concat list
ls *.mp4 | awk '{print "file '\''" $0 "'\''"}' > concat.txt

# 3. Concat (assumes all are same codec/fps from seedance — they are)
ffmpeg -f concat -safe 0 -i concat.txt -c copy sofia_longform_master.mp4

# 4. Add the end-card png as a 5s tail
ffmpeg -loop 1 -t 5 -i a045902e-*.png -vf "scale=1080:1920,setsar=1" -r 30 endcard.mp4
ffmpeg -f concat -safe 0 -i <(echo -e "file 'sofia_longform_master.mp4'\nfile 'endcard.mp4'") -c copy sofia_longform_final.mp4
```

That's the cleanest path if you want a single command-line stitch with no editor. Output is a 2:50 master ready for upload to YouTube Shorts / Reels / TikTok / paid ads.
